在 B 站上听到「乱翻书」博客，又在 X 上看到不少宣传 Muse 的内容，于是开始好奇 personal agent 到底是什么。顺着这个念头找到了 today.ai——一个把个人助手做进首页的产品。

入口的演进：注意力一次次被更高效地变现

回顾互联网入口的变迁，会发现一个规律：每一次入口升级，都让人的注意力被更高效地变现。

邮件原本是点对点通信，今天却塞满了营销邮件——我的常用邮箱躺着 4032 封未读，和重要的人之间的通信被淹没在垃圾堆里。短信在 1993 年成为商业服务，到 2026 年唯一的作用是收验证码，一个用了 20 年的号码被毁掉，只需要每天的几条"垫资、私人借钱"。

再到门户、搜索、短视频。Yahoo 想把流量留在站内，Google 却帮用户尽快离开、找到最相关的外部网站，凭这个理念成了新入口。而今天的抖音日均停留 2 小时，加上微信的 1.5 小时，几乎占去一个人一天真正有意义时间的一半。人类像一块被反复挤压的海绵，再也挤不出多余的注意力了。

入口的初衷都是为用户高效获取信息，但越高效的方式，越容易被注意力的变现价值绑架。如果这个世界会有一个荒坂公司，那它可能就是 ByteDance。

Personal Agent：下一个入口

AI 太强了。当模型能理解你、帮你订票、预定餐厅、处理琐碎事务时，个人助手成为下一个入口几乎是顺理成章的事。它会管理你的信息、安排你的日程，在你和外部世界打交道时充当代理人。如果它真的懂你，就不只是工具，而是赛博世界里类似《Her》那样的存在——重要到像你无法想象失去微信、失去手机一样。

但 personal agent 能不能成为一个好入口，关键从来不在模型能力，也不在 harness。模型一定会越来越强。真正的问题是它忠于谁。

真正的问题：它忠于谁

一个 agent 的收入结构，决定了它站在谁那一边。收入来自广告，它就有动力影响你的选择；从每笔交易抽佣，它就有动力让你消费；拿停留时长衡量成功，它最终也会变成另一块让你离不开的屏幕。

真正属于个人的 agent，需要一些近乎宪法级别的底线约束：明确区分建议和商业推荐，不因为替商家成交而拿任何形式的奖励。它衡量成功的标准，不该是为背后的公司创造了多少利润，而是为你节省了多少时间、提升了多少生活质量。

最好的 agent 让屏幕消失

最好的 personal agent 不应该让人更依赖屏幕，而是让屏幕逐渐消失。身体需要活动时催你站起来，真正重要的人发来消息时，它从四千封未读里把那封信捞出来；能在后台完成的事，它不该要求你打开 App、走过五个页面再贡献一次日活。

它一定会成为入口，只是希望这个入口不会被算法和商业利益完全绑架。免费的才是最贵的——订阅制反而可能是最可靠的商业模式。
