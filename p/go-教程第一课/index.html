一、教程下载与运行

1. 下载官方交互式教程

Go 官方提供了交互式学习教程 Tour of Go，可以下载到本地运行。

1

go install golang.org/x/website/tour@latest

安装完成后，在终端执行：

1

tour

启动本地教程服务，然后在浏览器访问终端提示的地址。

官方在线教程：

https://go.dev/tour/welcome/1

1. 常见的包

Go 的标准库提供了大量开箱即用的功能。

包名 用途
fmt 格式化输入输出

strings 字符串处理
time 时间和日期处理
os 操作系统相关功能
net/http HTTP 客户端和服务器
encoding/json JSON 编解码

2. 导入包

方式一：逐个导入 

1
2

import "fmt"
import "math"

方式二：分组导入

推荐使用分组导入：

1
2
3
4

import (
    "fmt"
    "math"
)

3. 导出名称

Go 使用首字母大小写来控制标识符是否可以被其他包访问。

首字母大写：导出

首字母大写的名称可以被其他包访问。

1

fmt.Println(math.Pi)

例如：

1

math.Pi

其中 Pi 首字母大写，因此可以从 math 包外部访问。

首字母小写：未导出

首字母小写的名称只能在当前包内部使用。

1

math.pi

外部无法访问。

核心规则：

  • 大写开头 → 导出 → 其他包可以访问
  • 小写开头 → 未导出 → 仅当前包可以访问

4. 函数定义

Go 函数的基本格式：

1
2
3

func 函数名(参数名 参数类型) 返回类型 {
    // 函数体
}

例如：

1
2
3

func add(x int, y int) int {
    return x + y
}

参数类型简写

如果连续多个参数类型相同，可以只写最后一个参数的类型：

1
2
3

func add(x, y int) int {
    return x + y
}

这与下面的写法完全等价：

1
2
3

func add(x int, y int) int {
    return x + y
}

5. 变量

Go 使用 var 声明变量。

1
2

var age int
var name string

如果变量声明时没有进行初始化，Go 会自动赋予该变量对应类型的零值。

类型 零值
整数类型 0
浮点类型 0
bool false
string ""
指针 nil
切片 nil
Map nil
Channel nil
Function nil
Interface nil

例如：

1
2
3
4
5
6
7

var age int
var name string
var active bool

fmt.Println(age)    // 0
fmt.Println(name)   // ""
fmt.Println(active) // false

6. 短变量声明

在函数内部，可以使用 := 进行短变量声明。

1
2
3
4
5
6

func main() {
    name := "Go"
    age := 20

    fmt.Println(name, age)
}

:= 会同时完成：

  1. 创建变量
  2. 推断变量类型
  3. 赋值

例如：

1

a, b := swap("hello", "world")

注意

:= 不能用于函数外部的包级变量声明。

错误：

1
2
3

package main

name := "Go" //

正确：

1
2
3

package main

var name = "Go" //

三、Go 基本类型

Go 的基本类型主要包括布尔、字符串、整数、浮点数和复数。

类别 类型 别名 / 关联 说明
布尔 bool - true 或 false
字符串 string - 不可变字节序列，通常存储 UTF-8 编码文本
有符号整数 int - 平台相关，通常为 32 位或 64 位
int8 - -128 ~ 127
int16 - -32768 ~ 32767
int32 rune 常用于表示 Unicode 码点
int64 - 64 位有符号整数
无符号整数 uint - 平台相关，与 int 位宽通常相同
uint8 byte 0 ~ 255，常用于表示原始字节
uint16 - 0 ~ 65535
uint32 - 32 位无符号整数
uint64 - 64 位无符号整数
uintptr - 足以存储指针地址的无符号整数
浮点数 float32 - 单精度浮点数
float64 - 双精度浮点数，通常优先使用
复数 complex64 - 实部和虚部均为 float32
complex128 - 实部和虚部均为 float64

byte 和 rune

这两个类型在 Go 中非常常见：

1
2

type byte = uint8
type rune = int32

因此：

1
2

var b byte
var r rune

分别可以理解为：

  • byte → 一个字节，常用于处理二进制数据
  • rune → 一个 Unicode 码点，常用于处理字符

例如：

1
2
3

var r rune = '中'

fmt.Println(r)

四、类型转换

Go 不会自动进行大多数数值类型之间的隐式转换。

需要使用：

1

T(v)

其中：

  • T 是目标类型
  • v 是需要转换的值

例如：

1
2
3
4

var x int = 10
var y float64 = float64(x)

fmt.Println(y)

也可以：

1
2
3
4

var a float64 = 10.5
var b int = int(a)

fmt.Println(b) // 10

注意：浮点数转换为整数时，小数部分会被截断。

1. 查看变量类型

可以使用 fmt.Printf 的 %T 查看变量类型：

1

fmt.Printf("v is of type %T\n", v)

例如：

1
2
3

name := "Go"

fmt.Printf("name is of type %T\n", name)

输出：

1

name is of type string

五、常量

Go 使用 const 定义常量：

1

const Pi = 3.14

常量创建后不能重新赋值：

1
2
3

const Pi = 3.14

// Pi = 3.14159 //

常量不能使用 :=

错误：

1

Pi := 3.14 // ❌

正确：

1

const Pi = 3.14 //

package main

import "fmt"

const Pi = 3.14

func add(x, y int) int {
    return x + y
}

func main() {
    name := "Go"
    age := 20

    result := add(10, 20)

    fmt.Println("Hello,", name)
    fmt.Println("Age:", age)
    fmt.Println("Result:", result)
    fmt.Println("Pi:", Pi)

    fmt.Printf("name type: %T\n", name)
    fmt.Printf("age type: %T\n", age)
}

这个程序综合使用了：

  • package
  • import
  • const
  • func
  • :=
  • int
  • string
  • 函数调用
  • fmt.Println
  • fmt.Printf
  • %T 类型格式化
