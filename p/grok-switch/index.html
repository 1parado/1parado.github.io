Grok switch

Grok Build 的安装方法，以及 grok build switch 的三种能力——公益站、CPA 文件导入、注册机号池，外加手机远程控制

Sep 12, 2026
1 minute read

最近站内经常能看到佬友发 grok 公益站的 URL 和 KEY、grok 的 CPA 文件，还有分享 grok 注册机的。这些东西各自解决一段问题，但要来回切换就挺麻烦。grok build switch 就是把这几件事收在一个界面里。

先记一下怎么装，再说它能干什么。

一、安装 Grok Build

macOS / Linux / WSL：打开终端（Terminal），输入以下命令并回车：

1

curl -fsSL https://x.ai/cli/install.sh | bash

Windows：打开 PowerShell（推荐以管理员身份运行），输入以下命令并回车：

1

irm https://x.ai/cli/install.ps1 | iex

二、安装 grok build switch

如果你只想在 grok build 中使用 grok-4.5，那么不需要选注册机，也不需要搞 CPA、CC-Switch。直接在 Release 下安装最新版本的 grok build switch 即可，包括托盘和 GUI 两种形态，任选其一下载使用。

三、三种能力

该项目同时具备三种能力，对应三种不同的取用方式。

1. 公益站

用过 cc-switch 的都知道，为了方便切换公益站，ccs 只需要通过可视化的方式配置 URL、KEY、MODEL 即可。grok build switch 同样如此：

  • 只需要填入 URL 和 Key；
  • 可以自动获取模型，并启用模型；
  • 一键切换，十分方便。

2. CPA 文件

CPA 就是 CliProxyAPI，一个开源项目。站内好多佬友都会发几百个、几千个 grok 的 CPA 认证文件，只要导入 CPA 中就可以得到 URL 和 Key，然后就可以导入到编程工具中。grok build switch 同样支持。

用法：

  1. 打开设置，找到 grok auth json；
  2. 把佬友们发的成百上千个 json 文件压缩后放在一个文件夹下，然后导入，会自动生成 URL 和 Key；
  3. 仅仅只需要配置模型即可；
  4. 导入成功之后，找到立即巡检来检查账号状态。

3. 注册机（需要 cloudflare 邮箱 API）

如果你不想和其他人用相同的 CPA 文件，那么可以通过注册机自己注册几十个 free 号，组成号池，每天自给自足也可以。

⚠️ 当前项目注册机注册的时候请保持页面可见，也就是需要打开页面看到下面的 cloudflare 验证通过，否则容易注册失败！

几个使用要点：

  • 默认注册成功的号池直接就放在 CPA 导入文件下，无需额外配置；
  • 注册成功之后出现 403 并不是账号不可用，可以启动巡检，一般注册成功之后都是可用的；
  • 一个 free 账号现在大概是 100 万。

状态码含义：

状态码 含义
200 账号可用
403 不代表不可用，启动巡检确认即可
429 账号额度用光

四、聊天与远程

在设置里勾选允许手机访问，只要你的手机、平板、电脑在同一个局域网下，就可以通过手机来控制电脑上的 grok build。

扫码配对之后，就能在移动端管理你的 grok 公益站，以及远程使用 grok build。同时还支持上传自定义壁纸，让你的 grok switch 看起来更美观。
